# Smart Fulfilment & Delivery Optimisation

A Python prototype for analysing logistics operations and exploring ways to improve delivery performance, demand planning, inventory decisions, and delivery routes.

## Project Overview

This project generates synthetic order data and runs it through a small logistics-analysis pipeline. It is intended as a starting point that can later be adapted to real datasets.

## Features

- **Synthetic order data:** Generates sample orders with delivery locations, weights, promised delivery times, and order dates.
- **Data cleaning:** Removes duplicate orders, fills missing weights, filters extreme delivery-time outliers, and creates date-based features.
- **Logistics KPIs:** Calculates on-time delivery, OTIF (On Time In Full), average delivery cost, and average delivery duration.
- **Delivery-zone clustering:** Uses K-Means to group orders by geographic coordinates.
- **Delivery-time prediction:** Trains a Gradient Boosting regression model and reports mean absolute error (MAE).
- **Demand forecasting:** Forecasts demand using lag and rolling-average features, then estimates a reorder point.
- **Route optimisation demo:** Compares a nearest-neighbour route with a 2-opt improvement heuristic.

## Setup and Run

1. Clone the repository:

   ```bash
   git clone <YOUR-GITHUB-REPOSITORY-URL>
   ```

2. Move into the project folder:

   ```bash
   cd <YOUR-REPOSITORY-FOLDER>
   ```

3. (Recommended) Create and activate a virtual environment:

   **Windows**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

   **macOS/Linux**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

4. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Run the pipeline:

   ```bash
   python logistics_analysis.py
   ```

The script prints the number of cleaned orders, baseline KPIs, orders per delivery zone, delivery-time model MAE, demand forecast WAPE and reorder point, and the baseline versus improved route length.

## Data Notes

The current version uses **synthetic data** generated by the script. It does not currently load Olist, DataCo Smart Supply Chain, or M5 data. The data-loading function can be adapted to read a real dataset when one is selected.

## Limitations

- Results are based on synthetic data and should not be treated as real-world logistics performance.
- The route-optimisation demo uses randomly generated points and Euclidean distances; it is a prototype rather than a road-network routing system.
- Forecasting and machine-learning scores depend on the generated sample data and are not guarantees of real-world performance.
